# COACHTECH フリマアプリ（模擬案件）

COACHTECH のカリキュラム課題として作成したフリマアプリです。  
Laravel を用いて、会員登録から商品出品・購入・決済までの一連の流れを実装しています。

---

## アプリ概要

ユーザー同士で商品を出品・購入できるフリマアプリです。  
ログイン機能を前提とし、商品一覧・商品詳細・購入・マイページなどの基本機能を備えています。

---

## 主な機能一覧

### 認証関連
- 会員登録
- ログイン
- ログアウト

### 商品関連
- 商品一覧表示
- 商品詳細表示
- 商品出品
- 商品検索（キーワード検索）
- 購入済み商品の「Sold」表示

### マイページ
- 出品した商品の一覧表示
- 購入した商品の一覧表示
- タブ切り替え表示

### ユーザー機能
- プロフィール表示
- プロフィール編集（ユーザー名・住所・郵便番号など）
- 配送先情報の登録・変更

### いいね・コメント
- 商品へのいいね登録／解除
- いいね数の表示
- 商品へのコメント投稿
- コメント数の表示

### 購入・決済
- 商品購入機能
- Stripe（テスト環境）によるクレジットカード決済
- 購入完了画面の表示
- 購入後、マイページ購入履歴への反映

## テストについて

本アプリは **自動テストではなく、すべて手動で動作確認**を行っています。

### 確認済み項目
- 会員登録（正常系・未入力時のバリデーション）
- ログイン（正常系・誤入力時のエラー表示）
- 商品一覧／商品詳細の表示
- 商品出品・表示反映
- いいね登録／解除と件数反映
- コメント投稿と表示
- 商品購入フロー
- Stripe テスト決済の実行
- 購入完了画面の表示
- マイページへの購入履歴・出品履歴の反映
- プロフィール編集・住所登録

---

## 補足

- Stripe 決済は **テスト環境（Sandbox）** を使用しています。
- 商品画像が未登録の場合は、NO IMAGE が表示される仕様です。
- 本アプリは学習目的で作成した模擬案件です。
